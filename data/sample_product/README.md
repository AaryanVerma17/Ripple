# Rover Alpha sample data

A fictional small rover used to demonstrate change impact analysis. Every value and price is invented.

The executable source is `services/api/app/data/rover_alpha.json`, generated by `scripts/build_dataset.py`. The CSV files and
`evidence.json` here are exports of the same data for inspection. Re-run `python scripts/build_dataset.py` after editing it.

Wiring ratings are deliberately missing so the app demonstrates `unknown` handling and the "supply a value" flow.
Catalogue parts (`catalog.csv`) are fictional and exist so the app can price fixes.
